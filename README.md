# Субтитры Саши

Живые субтитры для OBS — для любого стримера. Ничего устанавливать не нужно: речь распознаёт сам браузер, а готовый текст уходит в OBS через встроенный WebSocket. Python и журналы программы не обязательны — это запасной путь для тех, у кого уже есть свои журналы.

Лицензия MIT. Автор — Sasha AI.

> **Новое — [STTTS](https://github.com/andreyshapira1983-sketch/sasha-sttts):** те же субтитры плюс чужой голос вместо вашего и чат Twitch голосами — всё в одном пульте. Пульт: https://andreyshapira1983-sketch.github.io/sasha-sttts/

## Три шага

1. **Включите WebSocket в OBS.** OBS 28 и новее уже умеет это сам: `Сервис → Настройки WebSocket-сервера → Включить`, задайте пароль (или оставьте пустым). Запомните порт — по умолчанию `4455`.
2. **Добавьте в OBS источник «Браузер».** URL вида
   `https://andreyshapira1983-sketch.github.io/sasha-subtitles/overlay.html#ws://127.0.0.1:4455|ваш-пароль`,
   ширина `1920`, высота `1080`. Пароль стоит после `#` — эта часть адреса не уходит в запросах и не попадает в журналы сервера. Если пароля нет, хвост короче: `#ws://127.0.0.1:4455`.
3. **Откройте `control.html` в Chrome или Edge** (не в OBS!). Проверьте адрес и пароль OBS, нажмите большую кнопку «Начать» и разрешите браузеру доступ к микрофону. Говорите — субтитры появятся в OBS. До нажатия «Начать» страница ничего не слушает: микрофон включается только по кнопке, «слушаю» появляется после того, как браузер действительно начал слушать.

Готовые страницы, ничего скачивать не нужно:

* пульт распознавания — **https://andreyshapira1983-sketch.github.io/sasha-subtitles/control.html** (открыть в Chrome или Edge);
* картинка для OBS — `https://andreyshapira1983-sketch.github.io/sasha-subtitles/overlay.html#ws://127.0.0.1:4455|ваш-пароль`.

Если браузер спросит разрешение на доступ к устройствам в локальной сети — разрешите: так страница достучится до OBS на вашем же компьютере.

## Почему распознавание не в OBS

Источник «Браузер» в OBS — это картинка без доступа к микрофону и без распознавания речи. Поэтому микрофон слушает обычная страница `control.html` в Chrome или Edge, а текст передаётся в OBS через его WebSocket. В самом OBS открыт только `overlay.html` — он ничего не слушает, а показывает то, что пришло с пульта.

## Что программа делает с вашей речью

Распознавание речи делает браузер, а не эта программа:

* **Chrome** отправляет звук на сервер Google — так устроено встроенное распознавание Chrome;
* **Edge** отправляет звук на сервер Microsoft — так устроено распознавание Edge.

Это честное предупреждение: без отправки звука в облако браузер не умеет распознавать речь. Сама программа «Субтитры Саши» ничего не хранит и никуда больше не отправляет: текст идёт только в OBS WebSocket на вашем же компьютере (`ws://127.0.0.1:4455`). Никаких других адресов на страницах нет. В браузерном пути пароль OBS хранится только в `localStorage` вашего браузера; в Python-пути — ещё и в `config.json`, там же, где вы его указали. Записи речи программа не ведёт.

## Что умеет

* Имя говорящего и его цвет — по умолчанию «Ведущий» и голубой.
* Не больше двух строк на экране; длинная фраза идёт частями, и в конце оборванной части стоит «…» — видно, что продолжение следует.
* Время показа считается по длине текста (0,1 секунды на знак, от 3 до 12 секунд), потом субтитры плавно исчезают.
* Зрители видят только готовые фразы: текст, который браузер ещё распознаёт и переписывает на ходу, на экран не попадает. Кому нужен «живой» показ, допишите в адрес `?live=1` перед `#`: `overlay.html?live=1#ws://127.0.0.1:4455|ваш-пароль`. Тогда промежуточный текст будет бледнее готового и не перебьёт готовую фразу.
* Чёрная обводка — субтитры видны и на белом, и на чёрном фоне.
* Мат закрывается звёздочками: «пиздец» → «п*****», реплика при этом не пропадает. Корень, начинающийся с `^`, срабатывает только в начале слова: `^бля` закроет «бля» и «бляха», но не тронет «рубля».
* Автоправка готовых фраз: заглавные буквы, точки и вопросы, осторожные запятые, свой словарь замен.
* Автоперезапуск распознавания после паузы или ошибки, автоподключение к OBS после обрыва.
* Всё работает на вашем компьютере: сервер субтитров — только `127.0.0.1`, внешних адресов нет.

## Автоправка

Распознавание в Chrome и Edge выдаёт русский текст сплошной строкой: «привет всем как дела сегодня будем играть». Автоправка на пульте делает его читаемее — бесплатно, без установки и без интернета, прямо на странице.

**Что она делает** (каждое правило можно выключить галочкой на пульте):

1. **Свой словарь замен.** Таблица «было → стало» на пульте: `твич → Twitch`, `ютуб → YouTube`, `дискорд → Discord`, `обс → OBS` и любые ваши пары (можно целые фразы). Работает без учёта регистра и только по целым словам: «обс» заменится, «обстановка» — нет. Словарь хранится только в вашем браузере; есть кнопки «Экспорт» и «Импорт» в JSON-файл.
2. **Заглавная буква** в начале фразы и после `.`, `!`, `?`, `…`.
3. **Знак в конце:** `?`, если фраза начинается с вопросительного слова («как», «что», «почему», «где», «когда», «кто», «какой», «сколько», «разве», «неужели» и т. п.) или содержит частицу «ли» после первого слова; иначе `.`. Для английского — свой список (`what`, `why`, `how`, `where`, `do`, `is`, `can`…).
4. **Запятые — только по простым и надёжным правилам:** перед «что», «чтобы», «потому что», «так как», «если», «когда», «который» (и формы), «где», «куда», «хотя» — если впереди уже хотя бы два слова; перед «но», «а», «однако», «зато» — если это не первое слово; вводные слова в начале фразы («Короче, …»). Исключения тоже учтены: «потому что», «так что», «а что», «ну что», «вот что», «то, что», «а если».
5. **Мелочи:** двойные пробелы схлопываются, пробел перед знаком препинания убирается; числа и буква «ё» не трогаются. Слова с дефисом («как-то», «что-то», «где-то») считаются одним словом и не дают ложных вопросов и запятых.

Примеры: «как дела» → «Как дела?», «я думаю что ты прав» → «Я думаю, что ты прав.», «хочу играть но надо работать» → «Хочу играть, но надо работать.», «сегодня твич и обс» → «Сегодня Twitch и OBS.», «как-то так» → «Как-то так.»

**Чего она не умеет** (честно):

* Это не грамматика и не искусственный интеллект: правил мало, и они нарочно осторожные. Лучше не поставить запятую, чем поставить лишнюю.
* Запятая перед «как», обращения в середине фразы, сложные обороты и вложенные предложения не разбираются. Поэтому «привет всем как дела» останется «Привет всем как дела.» — без запятой перед «как» и без вопроса, потому что фраза начинается не с вопросительного слова.
* Вопрос определяется по началу последнего предложения (и частице «ли»), а не по смыслу: «ты дома» останется утверждением.
* Ошибки распознавания исправляются только словарём: «твич» → «Twitch», но «привте» → «привте».
* Промежуточный текст не правится вообще — только готовые фразы, иначе текст прыгал бы на экране.
* Под каждой фразой в истории видно «как распознано» и «как исправлено», чтобы было понятно, что именно изменилось.

## Для продвинутых: журналы и Python

Если ваша программа уже пишет журналы, можно обойтись без браузера: `server.py` прочитает их и отправит текст в тот же OBS WebSocket. Если журналов нет — этот раздел можно не читать, браузерного пути достаточно.

### Формат журналов

`logs/said.jsonl` — по одной JSON-записи в строке; берётся поле `text`:

```json
{"ts": 1700000000.0, "text": "Привет! Это тестовые субтитры."}
```

`logs/hear_stream.log` — строки распознанной речи вида:

```
[слышу] Ведущий (микрофон): Проверка связи, как меня слышно?
```

Берутся только строки, начинающиеся с `[слышу]`: имя — до скобки, текст — после первого двоеточия. Остальные строки пропускаются. Журналы могут быть любыми — важны только эти два формата. Образцы в `samples/` придуманы для демонстрации: настоящей речи в них нет.

### Запуск Python-пути

```
python server.py            # своя страница субтитров: http://127.0.0.1:8765/
python server.py --demo     # демо на придуманных образцах
python server.py --obs      # без своей страницы: сразу в OBS WebSocket
```

В режиме `--obs` источник «Браузер» в OBS указывает на `overlay.html#ws://127.0.0.1:4455|пароль` — так же, как в браузерном пути. Старый режим со своей страницей на `127.0.0.1:8765` работает как раньше: в OBS добавьте источник «Браузер» с адресом `http://127.0.0.1:8765/`.

Порт и пароль OBS для Python-режима задаются в `config.json` (раздел `obs`). Пути к журналам, число строк и знаков, цвета говорящих и корни мата — тоже в `config.json`; настройки читаются при запуске.

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `said_log` | `logs/said.jsonl` | Журнал с JSON-записями. |
| `hear_log` | `logs/hear_stream.log` | Журнал со строками `[слышу]`. |
| `demo_said_log` | `samples/said.jsonl` | Журнал для демо-режима. |
| `demo_hear_log` | `samples/hear_stream.log` | Журнал ушей для демо-режима. |
| `port` | `8765` | Порт своей страницы. Адрес всегда `127.0.0.1`. |
| `obs.host` | `127.0.0.1` | Адрес OBS WebSocket. |
| `obs.port` | `4455` | Порт OBS WebSocket. |
| `obs.password` | пусто | Пароль OBS WebSocket. |
| `columns` | `34` | Сколько знаков максимум в одной строке. |
| `max_lines` | `2` | Сколько строк максимум на экране. |
| `seconds_per_char` | `0.1` | Секунд показа на один знак. |
| `min_seconds` | `3.0` | Минимальное время показа. |
| `max_seconds` | `12.0` | Максимальное время показа. |
| `font_size` | `44` | Размер шрифта в пикселях. |
| `speakers` | `host`: Ведущий `#8fd8ff`, `sasha`: Саша `#ff9ee6` | Имена и цвета говорящих. Ключ — значение поля `speaker` в журнале. |
| `banned_words` | `блять`, `хуй`, `пизд`, `ебал` | Запретные корни (можно с `^`). |

Пауза: создайте файл `PAUSE` рядом с программой — показ остановится.

## Тесты

Node — без пакетов и установки (из папки проекта; Node сам находит тесты в `tests/`):

```
node --test
```

Python — только стандартная библиотека:

```
python -m unittest -v
```

Тесты страниц работают без браузера и без OBS: поддельные DOM, WebSocket и часы. Интернет в тестах не используется — только поддельные объекты и свой компьютер (`127.0.0.1`).
