# Субтитры Саши

Живые субтитры для OBS: программа читает журналы ИИ-ведущей и распознанной речи стримера и выводит текст поверх видео.

![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg) ![Python 3.11+](https://img.shields.io/badge/python-3.11%2B-blue.svg) ![Без зависимостей](https://img.shields.io/badge/dependencies-none-brightgreen.svg)

## Что умеет

- Два говорящих: у каждого своё имя и свой цвет.
- Перенос строк: не больше N знаков в строке и не больше 2 строк на экране; длинная реплика идёт частями.
- Время показа считается по длине текста (0,06 с на знак, от 2 до 8 с), потом субтитры плавно исчезают.
- Мат закрывается звёздочками: «пиздец» → «п*****», реплика при этом не пропадает.
- Команды эмоций «э:» и пустые реплики не показываются.
- Пауза файлом `PAUSE` рядом с программой.
- Демо-режим `--demo` на придуманных образцах из `samples/`.
- Сервер слушает только `127.0.0.1`.
- Защита от двойного запуска: вторая копия на том же порту не стартует.
- Только стандартная библиотека Python 3.11, без установки зависимостей.

## Как это работает

```
logs/said.jsonl ───────┐
                       ├──> server.py ──> /lines?after=N ──> overlay.html ──> OBS «Браузер»
logs/hear_stream.log ──┘
```

`server.py` читает только новые строки обоих журналов, фильтрует и режет текст на экраны, а `overlay.html` раз в полсекунды забирает новые реплики и показывает их поверх видео.

## Быстрый старт

1. Скачайте папку проекта (или склонируйте репозиторий).
2. Запустите демо: `python server.py --demo`. В консоли появится адрес страницы.
3. В OBS добавьте источник «Браузер»: URL `http://127.0.0.1:8765/`, ширина 1920, высота 1080, «OK».

Для настоящих журналов положите их в `logs/` и запустите `python server.py` (без `--demo`) — программа покажет только то, что появится после запуска. Пути можно поменять в `config.json`.

## Формат журналов

`logs/said.jsonl` — по одной JSON-записи в строке:

```json
{"ts": 1700000000.0, "text": "Привет! Это тестовые субтитры."}
```

`logs/hear_stream.log` — строки распознанной речи:

```
[слышу] Ведущий (микрофон): Проверка связи, как меня слышно?
```

Берутся только строки, начинающиеся с `[слышу]`: имя — до скобки, текст — после первого двоеточия. Остальные строки пропускаются.

Образцы в `samples/` придуманы специально для демонстрации: настоящей речи в них нет.

## Настройки

| Ключ | По умолчанию | Смысл |
|---|---|---|
| `said_log` | `logs/said.jsonl` | Журнал ИИ-ведущей (JSONL). |
| `hear_log` | `logs/hear_stream.log` | Журнал распознанной речи. |
| `demo_said_log` | `samples/said.jsonl` | Журнал для демо-режима. |
| `demo_hear_log` | `samples/hear_stream.log` | Журнал ушей для демо-режима. |
| `port` | `8765` | Порт сервера. Адрес всегда `127.0.0.1`. |
| `columns` | `34` | Сколько знаков максимум в одной строке на экране. |
| `max_lines` | `2` | Сколько строк максимум на одном экране. |
| `seconds_per_char` | `0.06` | Секунд показа на один знак текста. |
| `min_seconds` | `2.0` | Минимальное время показа одного экрана. |
| `max_seconds` | `8.0` | Максимальное время показа одного экрана. |
| `font_size` | `44` | Размер шрифта в пикселях. |
| `speakers` | Саша `#ff9ee6`, Ведущий `#8fd8ff` | Имена и цвета говорящих. |
| `banned_words` | `блять`, `хуй`, `пизд`, `ебал` | Запретные корни для маскировки звёздочками. |

Пути считаются от папки программы. Настройки читаются при запуске: после правки `config.json` перезапустите сервер. Запретный корень ищется внутри слова без учёта регистра: первая буква остаётся, остальные заменяются звёздочками, знаки препинания вокруг сохраняются.

## Тесты

```
python -m unittest -v
```

31 тест: 19 про текст (переносы, время показа, маскировка мата, команды «э:»), 10 про журналы (только новое, битые строки, неполная строка, укорочение файла, демо-пути) и 2 про сервер (запрет повторного занятия порта).

## Как появился проект

Код написан ИИ (DeepSeek) по заданию ИИ-ведущей Саши (Claude) и проверен ею. Идея подсмотрена у проекта OBS Transcript (лицензия MIT): https://github.com/akabe/obs-transcript. Код оттуда не копировался — вся реализация своя, из проекта взята только сама идея субтитров для OBS.
